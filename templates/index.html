Project overview

About the project

This is a binary classification project based on the Titanic passenger dataset. The trained model estimates which of two classes a passenger belongs to: survived or did not survive.

Project Goal

Predict the survival outcome from passenger information.

ML Task

Supervised learning with two possible output classes.

Dataset

Passenger records containing travel and demographic details.

Web Interface

Dataset information

Input columns explained

The model uses seven input features. Passenger identifiers, names, ticket numbers, and cabin numbers are excluded.

Titanic model input columns and descriptions
Column Type Description Example
Pclass Numeric Ticket class of the passenger 1, 2, 3
Sex Categorical Passenger's recorded sex male, female
Age Numeric Passenger's age in years 22
SibSp Numeric Siblings and spouses aboard 1
Parch Numeric Parents and children aboard 0
Fare Numeric Passenger fare in dataset units 7.25
Embarked Categorical Port where the passenger embarked C, Q, S
Survived Target Historical outcome used for training 0 or 1

Preprocessing: Missing numerical values are imputed using the median; missing categorical values use the most frequent value. Categorical inputs are one-hot encoded and numerical inputs are standardized.

Model details

Gaussian Naive Bayes

Gaussian Naive Bayes is a probabilistic classification algorithm based on Bayes' theorem. It estimates class probabilities and assumes continuous features follow a Gaussian distribution within each class, with conditional independence between features.

GaussianNB Binary Classification Probability Estimates Scikit-learn

Prediction workflow

  1. Collect passenger details from the form.
  2. Impute, encode, and scale the inputs.
  3. Apply the trained Gaussian Naive Bayes model.
  4. Display the predicted class and estimated survival probability.

Model evaluation

Accuracy is calculated on a held-out 20% test split when there are enough usable records and both classes have sufficient examples.

  • Accuracy: fraction of test predictions that are correct.
  • Precision: how many predicted positives are correct.
  • Recall: how many actual positives are identified.
  • F1-score: balance between precision and recall.
Accuracy is data-dependent. It is not a guaranteed measure of performance on unseen real-world passengers.
